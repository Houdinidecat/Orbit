CÓMO ABRIR
Abre dist/index.html con tu navegador. No necesitas instalar nada ni tener un
servidor. Conserva la carpeta dist completa para que se carguen las imágenes y
los estilos. Los enlaces externos requieren conexión a internet.

TECNOLOGÍAS Y PLATAFORMA

https://docs.railway.com/quick-start

PUBLICACIÓN FUTURA
La estudiante realizará el despliegue en Railway por separado. Desde Railway,
selecciona el repositorio Houdinidecat/Orbit, conserva la raíz del repositorio
y despliega. Staticfile indica a Railpack que sirva dist/ mediante Caddy.
Después genera un dominio en el servicio y comprueba el sitio.
No se necesita activar GitHub Pages: GitHub guarda el código y Railway aloja
la página. Esta entrega no ha ejecutado ningún despliegue en Railway.
