1. PLATAFORMA Y TECNOLOGÍAS
Se seleccionó Railway como plataforma para alojar este sitio estático.
La página utiliza HTML5 para la estructura y CSS3 para la presentación.
No requiere JavaScript, un servidor de aplicaciones propio ni una base de
datos. Archivos principales: dist/index.html y dist/styles.css; las imágenes
y demás recursos se incluyen en dist/. El archivo Staticfile, en la raíz del
repositorio, contiene root: dist para que Railpack prepare el servidor Caddy.

2. RECURSO DE INTRODUCCIÓN CONSULTADO
Se consultó “Quick Start Tutorial”, recurso oficial de introducción a Railway
equivalente a “Getting Started”, y su apartado de despliegue desde GitHub:
https://docs.railway.com/quick-start
La guía modela la creación de un proyecto, la conexión de un repositorio,
el despliegue y la generación de un dominio.
También se consultó la documentación oficial del motor de construcción:
https://railpack.com/languages/staticfile/
Esta referencia explica la detección de sitios HTML y el archivo Staticfile.

4. PROCEDIMIENTO PARA LA FUTURA PUBLICACIÓN EN RAILWAY
La estudiante realizará el despliegue por separado. Estos pasos son una guía;
no constituyen evidencia de que la aplicación ya esté publicada:
1) Guardar los archivos del proyecto en el repositorio Houdinidecat/Orbit.
2) En Railway, crear un proyecto desde un repositorio de GitHub y seleccionar
   Houdinidecat/Orbit. Autorizar el acceso de Railway cuando se solicite.
3) Mantener la raíz del repositorio como directorio de trabajo. Staticfile
   contiene root: dist; Railpack reconoce el sitio y prepara Caddy. No se
   requieren comandos personalizados de construcción o inicio.
4) Iniciar el despliegue y revisar los registros del servicio.
5) Generar un dominio desde la configuración del servicio en Railway.
6) Abrir la dirección publicada y verificar logo, fondo, enlaces y footer.

GITHUB Y RAILWAY

No se necesita un segundo despliegue mediante GitHub Pages.
